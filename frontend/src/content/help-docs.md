# InsightOps 帮助文档

## 仪表盘概览

首页展示所有主机的实时监控状态、CPU/内存/磁盘使用率趋势图，以及最近的告警摘要。

- **设备连接状态**：在线（绿色）主机排在前面，离线（红色）排在后面
- **RDP 登录趋势**：按天/周/月查看 RDP 登录统计
- **AI 回收建议**：基于闲置天数、CPU、内存和在线状态量化评分

![运维概览看板](/docs-imgs/dashboard-overview.png)

---

## 设备管理

在设备管理页面可添加、编辑、删除监控主机。支持 SNMP/Agent 两种采集方式，点击主机 IP 可查看详细指标。

- 按在线/离线/闲置过滤设备
- 批量导入/导出设备清单
- 编辑主机归属信息（部门、负责人、联系方式）

![设备详情](/docs-imgs/device-detail.png)

---

## 告警规则

告警中心支持自定义阈值规则（CPU、内存、磁盘、网络），触发后可通过邮件或 Webhook 通知。

- 设置多级告警阈值
- 配置通知渠道（邮件、Webhook）
- 告警历史查询与统计

![告警中心](/docs-imgs/alerts-center.png)

---

## 日志分析

集中采集并分析主机系统日志和应用日志，支持关键词搜索、时间范围过滤和日志级别筛选。

- 实时日志流查看
- 关键词高亮搜索
- 日志级别（INFO/WARN/ERROR）筛选
- 时间范围过滤

---

## 用户与权限

支持多用户管理，分为管理员和普通用户角色。

- **管理员**：可管理设备和系统设置
- **普通用户**：仅可查看监控数据

## 设备在线状态判定

| 状态 | 条件 | 颜色 |
|------|------|------|
| 在线 (active) | 10 分钟内有客户端心跳上报 | 🟢 绿色 |
| 离线 (inactive) | 超过 10 分钟无心跳 | 🔴 红色 |

客户端通过 RDP 采集脚本（`neone-rdp-collector.ps1`）每 5 分钟发送一次心跳请求，
携带 `source_ip` 字段自动上报本机 IP。

## AI 回收建议 - 量化打分策略

回收建议基于四个维度加权评分，满分 100 分，无需配置 AI API Key 即可使用。

### 打分维度

| 指标 | 阈值 | 得分 | 说明 |
|------|------|:---:|------|
| **RDP 闲置天数**（权重 60%） | ≤ 6 天 | 0 | 活跃，不扣分 |
| | 7-13 天 | 5 | 刚闲置 |
| | 14-29 天 | 15 | 超过 2 周 |
| | 30-59 天 | 30 | 超过 1 个月 |
| | 60-89 天 | 45 | 超过 2 个月 |
| | 90-179 天 | 55 | 超过 3 个月 |
| | ≥ 180 天 | 60 | 超过半年 |
| | 无记录 | 10 | 无 RDP 数据 |
| **CPU 使用率**（权重 15%） | ≤ 5% | 15 | 持续极低负载 |
| | 5%-15% | 8 | 偏低 |
| | 15%-30% | 3 | 正常偏低 |
| | > 30% | 0 | 正常 |
| | 无数据 | 0 | 无数据不扣分 |
| **内存使用率**（权重 15%） | ≤ 10% | 15 | 严重空闲 |
| | 10%-25% | 8 | 偏低 |
| | 25%-50% | 3 | 正常偏低 |
| | > 50% | 0 | 正常 |
| | 无数据 | 0 | 无数据不扣分 |
| **在线状态**（权重 10%） | 当前离线 | 10 | 主机不在线 |
| | 在线 | 0 | 不扣分 |

### 总分判定

| 总分 | 评级 | 建议动作 |
|------|------|------|
| ≥ 60 | 🔴 强烈建议回收 | 可安全回收或关机；CPU/内存持续极低可降配 |
| 30-59 | 🟠 建议关注 | 已闲置超过 1 个月，联系负责人确认是否保留 |
| < 30 | 🟢 无需操作 | 当前使用状态正常，无需操作 |

### 计算公式

```
总分 = RDP闲置得分 + CPU得分 + 内存得分 + 在线状态得分
```
